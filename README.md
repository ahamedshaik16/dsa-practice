# DSA Practice

Java (17) + Maven + JUnit 5 workspace for practicing data structures & algorithms.

## Layout
- `src/main/java/dsa/<topic>/` – solutions (one class per problem)
- `src/test/java/dsa/<topic>/` – JUnit tests for each solution

## Commands
```
mvn test                       # run all tests
mvn test -Dtest=TwoSumTest     # run one
```
